## 1. Why This Portfolio Exists

Most CMA aspirants present *theory*. Recruiters hire on *evidence of business judgement*. This portfolio is built to demonstrate, end-to-end, that I can:

1. Pull real-world data (annual reports, RBI bulletins, Kaggle, MCA filings).
2. Apply costing & financial frameworks (marginal costing, variance, ratio analysis, DuPont).
3. Translate numbers into **actionable, ₹-quantified recommendations**.
4. Package the work for an **executive audience** — dashboards, one-pagers, decision memos.

Each project has the same skeleton so a hiring manager can scan in 90 seconds:
**Context → Data → Analysis → Insight → Recommendation → Quantified Impact.**

## 5. Design Principles Used Across All 4 Projects

1. **Insights > calculations.** Every variance / ratio is followed by *"so what?"* in plain English.
2. **₹-quantified recommendations.** No "improve efficiency" without "₹X Cr / year impact, Y month payback".
3. **Indian context.** Numbers in ₹ Cr / Lakh, GST-aware, Indian Accounting Standards (Ind AS), realistic Indian industry benchmarks.
4. **Audit-ready.** Each number traces back to a source cell or a documented assumption.
5. **Show your work.** Methodology files explain the *why* behind every formula choice (e.g., why weighted-average vs FIFO).
